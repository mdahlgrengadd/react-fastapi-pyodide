# Architecture Change: Bridge → ASGI

## ✅ Migration Complete

The project has been migrated from the **monkey-patching bridge** to the **clean ASGI architecture**.

---

## What Changed

### Before (Monkey-Patching)
- ❌ Used `bridge.py` (885 lines) to intercept FastAPI
- ❌ Monkey-patched `FastAPI` class at import time
- ❌ Custom dependency resolution logic
- ❌ Manual serialization handling
- ❌ Bypassed standard ASGI interface
- ❌ Special handling for OAuth2, forms, etc.

### After (Clean ASGI)
- ✅ Uses `asgi_server.py` (150 lines) for clean ASGI interface
- ✅ **Pure FastAPI** - no modifications or monkey-patching
- ✅ Standard ASGI 3.0 specification
- ✅ FastAPI handles everything natively
- ✅ All middleware works correctly
- ✅ OAuth2, forms, headers work out-of-the-box

---

## How It Works Now

```
┌─────────────────────────────────────┐
│   Browser (fetch request)           │
└───────────────┬─────────────────────┘
                │
                ↓
┌─────────────────────────────────────┐
│   PyodideEndpointExecutor (TS)      │
│   • Converts request to ASGI scope  │
│   • Calls Python ASGI server        │
└───────────────┬─────────────────────┘
                │
                ↓
┌─────────────────────────────────────┐
│   PyodideASGIServer (Python)        │
│   • ASGI 3.0 compliant interface    │
│   • Calls FastAPI via scope/recv/send│
└───────────────┬─────────────────────┘
                │
                ↓
┌─────────────────────────────────────┐
│   Unmodified FastAPI App            │
│   • No monkey-patching!             │
│   • All features work natively      │
│   • Middleware executes normally    │
│   • OAuth2 works out-of-the-box     │
└─────────────────────────────────────┘
```

## Migration Path (if needed to rollback)

To temporarily rollback to the bridge (not recommended):

1. Restore `bridge.py` in `constants.ts` API_FILES
2. Change `loadASGIServer()` back to `loadFastAPIBridge()`
3. Restore bridge method calls in PyodideEndpointExecutor

**Note:** The bridge is deprecated and should not be used going forward.

## Key Differences in Code

### Getting Endpoints

**Before (Bridge):**
```typescript
const endpoints = pyodide.runPython("bridge.get_endpoints()");
```

**After (ASGI):**
```typescript
const endpoints = pyodide.runPython("get_endpoints_from_app()");
```

### Executing Endpoints

**Before (Bridge):**
```python
result = await execute_endpoint(
    operation_id, path_params, query_params, body, headers
)
```

**After (ASGI):**
```python
# Build ASGI scope
scope = {
    'type': 'http',
    'method': 'GET',
    'path': '/users',
    'headers': [...],
    'body': b'...'
}

# Call ASGI server
response = await asgi_server.handle_request(scope)
```

### OpenAPI Schema

**Before (Bridge):**
```typescript
const schema = pyodide.runPython("bridge.get_openapi_schema()");
```

**After (ASGI):**
```typescript
const schema = pyodide.runPython("get_openapi_from_app()");
```
